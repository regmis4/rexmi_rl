Torque, speed and clipping

  • RR knee clipping: 7.75% pooled, 12.70% run 1 and 4.48% run 2. Longest contiguous episode is 1.36 s, at low speed.
  • Largest knee PD request: 65.86 Nm, FL knee at 226.265 s in run 2. Applied estimate remained 23.5 Nm. A base contact occurred about 40 ms earlier. A near-vertical obstacle is the operator's hypothesis, not measured ground geometry.
  • Wheel braking point is about −1.47 kW estimated mechanical power, not recovered battery power. FR high-speed motoring point is about +1.29 kW. Preserve these events rather than dismiss them as unloaded spin.
  • Logged limits and achieved speeds disagree for wheels. The installed implicit actuator ignores the deprecated velocity_limit setting; a realistic torque–speed replay is still needed.
